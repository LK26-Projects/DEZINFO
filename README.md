# DEZINFO

## Cel

Prototyp aplikacji do analizy wiarygodności informacji.

## Technologie

- Vite + JavaScript
- Supabase

## Podział funkcjonalności analizy

- walidacja danych wejściowych
- komunikacja z API/backendem
- prezentacja wyniku

## Aktualnie realizowane zadanie

Walidacja danych wejściowych.

## Zasada

Walidator ma być niezależny od DOM, CSS, `fetch` i Supabase.

## Kontrakt walidatora

`dane wejściowe -> { valid, value, errors }`

## Sekrety

Sekrety pozostają w `.env` i nie trafiają do repozytorium.
